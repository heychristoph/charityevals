## Drivers

1. `$missing_data_discount` (shared slider; thin is right: no household count, reach is goods ÷ a judged value per household).
2. `$uov_per_daly` (shared).
3. `recipients_consumption_share`: judgment; put it on the shared per-person anchor (finding 3).
4. `counterfactual_adj`: judgment without a reference class (finding 5).
5. `inkind_cash_equivalence`: judgment; one question only (finding 4).

`goods_per_household` hardly matters: on the log scale at these small gains the result is almost linear in the total value, so the reach judgment barely moves it. The goods' total value does matter, and it is understated by a fifth (finding 1). Among peers (American Red Cross 0.0045, Salvation Army 0.0052, Habitat 0.0054) the model sits where the evidence puts it. The summary's reason for the gap to the cause median (goods given in a rich country) holds. The fixes together move it to about 0.004–0.006.
