## Drivers

1. `initial_effect_sd`: sourced (one RCT, n = 66), 0.10–1.08 gives about 11× swing. The only way to tighten it is a second trial; nothing else exists.
2. `effect_duration_years`: a judgment, 0.35–2.5. Needs to be split so the anticipation part, which has no measurement, has its own row (finding 4).
3. `$daly_per_wellby`: a shared slider.
4. `evidence_adj`: a judgment, anchored on HLI's shrinkage of single trials; reasonable.
5. `@wellby_factors.wellbys_per_sd_year`: shared.

Missing from the drivers today: hospital costs saved (finding 1). Once it is a row, it may be the top or second driver. What would most improve the model: model that channel from Patel et al. (the full paper's cost figures, if reachable) with an explicit causal discount, and put the household size on the families the wishes actually reach.
