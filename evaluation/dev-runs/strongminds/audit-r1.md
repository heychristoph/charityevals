# Audit: strongminds-charityevals, round 1
Bottom line: 0.0457 WELLBYs/$ = 6.11× GiveDirectly (joint 0.037–334×). Verdict: **fix needed** (1 high).
Previous round: none (first round).

In WELLBY terms, the model is 6.05× the repo's `givedirectly-hli` (0.00755 WELLBYs/$). So the "× GiveDirectly" comparison within the wellbeing family doesn't depend on `uov_per_wellby`, even though that input tops the tornado.

## Drivers
1. **uov_per_wellby** (shared judgment, 2.1–15.9×). It's not model-specific. Within WELLBYs the model is 6.05× `givedirectly-hli`, so the write-up could lead with that comparison.
2. **initial_effect_sd** (sourced estimate, verified; 2.0–12.9×). It enters quadratically because duration = effect ÷ decay. That's the template's choice, but it should be stated where the range is discussed: the write-up does say it "enters twice".
3. **effect_decay_sd_per_year** (judgment; 3.1–12.2×). The anchors are real, but the slow end rests on uncontrolled pre-post data (finding 3).
4. **evidence_adj** (judgment; 3.1–10.2×). It has a reference class (Baird), but the anchor is misread (finding 1). This is the single most important fix: done properly, it moves the point to ~3.9×, or forces an explicit argument for crediting StrongMinds above Baird.
5. **household spillover ratio** (shared estimate; 4.5–8.1×). Shared fact. About 36% of clients are adolescents, for whom household spillovers are less studied.

What would most improve the model: re-anchor evidence_adj on Baird's per-attender continuous effects (Table A4) and the SDB-corrected Atuhumuza effect, and narrow the decay range to controlled evidence. When results come out, use the registered StrongMinds RCT (NCT07812311) as the primary anchor for both effect and decay.

Peer comparison: 6.1× sits between `givedirectly-hli` (1.0×) and `against-malaria-foundation-hli` (10.0×), well within 10× of peers. After the findings 1–3 fixes it would be about 3.9–5.7×.
